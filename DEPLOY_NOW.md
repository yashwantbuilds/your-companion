# 🚀 QUICK: Deploy to GitHub Pages in 2 Minutes

## The 4 Steps (Copy-Paste Ready)

### STEP 1: Make Sure Repository is PUBLIC
```
Go to: https://github.com/yashwantbuilds/your-companion/settings/general
Check: "Repository visibility" = PUBLIC (not Private)
If Private → Click "Change visibility" → Select "Public" → Confirm
```

---

### STEP 2: Enable GitHub Pages
```
Go to: https://github.com/yashwantbuilds/your-companion/settings/pages
```

You should see:

```
Build and deployment

Source
[Deploy from a branch ▼]

Branch: main        [▼]
Folder: / (root)    [▼]

[Save]
```

**Set exactly:**
- Branch: `main`
- Folder: `/ (root)`

Then click **Save**

---

### STEP 3: Wait 2-5 Minutes
GitHub is deploying your site...

---

### STEP 4: Visit Your Live Site
```
https://yashwantbuilds.github.io/your-companion/
```

Done! 🎉

## 📦 Available Tools

### 1. 📄 [JSON Beautifier](https://yashwantbuilds.github.io/your-companion/tools/json-beautifier/)
Format, validate, and minify JSON data instantly
- **Features:**
  - Beautify with customizable indentation (2, 3, 4 spaces or tabs)
  - Minify JSON for smaller file sizes
  - Validate JSON syntax with error messages
  - File upload support (.json, .txt)
  - Copy to clipboard & download
  - Real-time size comparison

### 2. 🔍 [Regex Finder](https://yashwantbuilds.github.io/your-companion/tools/regex-finder/)
Test and debug regular expressions with live matching
- **Features:**
  - Find all matches with regex patterns
  - Replace all matches with capture group support
  - Regex flags: global, case-insensitive, multiline
  - Common pattern examples
  - Real-time testing
  - Download results

### 3. ⏰ [Cron Builder](https://yashwantbuilds.github.io/your-companion/tools/cron-builder/)
Create and parse cron expressions for task scheduling
- **Features:**
  - Interactive expression builder
  - Parse existing expressions
  - Common preset expressions (hourly, daily, weekly, etc.)
  - Human-readable descriptions
  - Visual builder with field-based inputs

### 4. 🌍 [Timezone Converter](https://yashwantbuilds.github.io/your-companion/tools/timezone-converter/)
Convert times between different timezones
- **Features:**
  - 15+ major timezones worldwide
  - Automatic DST handling
  - Current time option
  - Quick timezone selection buttons
  - Real-time conversion

### 5. 📅 [Date Calculator](https://yashwantbuilds.github.io/your-companion/tools/date-calculator/)
Calculate date differences in multiple units
- **Features:**
  - Days, weeks, months, years calculations
  - Detailed time breakdown
  - Today button for quick reference
  - Perfect for project planning
  - Copy results

### 6. 🔤 [Text Case Converter](https://yashwantbuilds.github.io/your-companion/tools/text-case/)
Convert text between different cases
- **Features:**
  - 10 case conversion types
  - UPPERCASE, lowercase, Title Case
  - camelCase, PascalCase, snake_case
  - kebab-case, CONSTANT_CASE, tOGGLE cASE, Sentence case
  - Live preview
  - Character & word count
  - Bulk download

## 🚀 GitHub Pages Deployment

### Prerequisites
- GitHub account
- Git installed locally
- Repository access

### Steps

1. **Clone or Fork the Repository**
   ```bash
   git clone https://github.com/yashwantbuilds/your-companion.git
   cd your-companion
   ```

2. **Make Changes (if needed)**
   - Modify files in `/root` directory
   - Test locally by opening `index.html` in browser

3. **Push to GitHub**
   ```bash
   git add .
   git commit -m "Update: [your message here]"
   git push origin main
   ```

4. **Enable GitHub Pages**
   - Go to Repository Settings
   - Navigate to "Pages" section
   - Select Branch: `main`
   - Select Folder: `root` (or `/root`)
   - Click "Save"

5. **Wait for Deployment**
   - GitHub will deploy automatically (1-5 minutes)
   - Check "Environment" tab for status
   - Site will be live at: `https://<username>.github.io/your-companion/`

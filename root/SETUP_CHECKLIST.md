## 🔍 Search Console Setup

### Google Search Console
1. Go to https://search.google.com/search-console/
2. Click "Add property"
3. Enter: `https://yashwantbuilds.github.io/your-companion/`
4. Verify ownership (HTML file or DNS)
5. Submit sitemap:
   - Go to Sitemaps section
   - Enter: `/your-companion/sitemap.xml`
   - Click Submit

### Bing Webmaster Tools
1. Go to https://www.bing.com/webmasters/
2. Add site: `https://yashwantbuilds.github.io/your-companion/`
3. Verify ownership
4. Submit sitemap: `/your-companion/sitemap.xml`

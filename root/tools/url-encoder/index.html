💡 What is URL Encoding?

URL encoding converts special characters in URLs to a format that can be safely transmitted over the internet. For example, a space becomes "%20" and special characters like "&" become "%26".

📚 Common Examples

Space Hello World → Hello%20World
Special Characters email@example.com → email%40example.com
URL Parameters name=John&age=30 → name%3DJohn%26age%3D30
Slashes path/to/file → path%2Fto%2Ffile
